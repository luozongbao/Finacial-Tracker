Financial Tracker — UI mockups

Static design artefacts for the personal finance tracker: record income and spending, then search and sum over a period (day, week, month, year).

Placeholder gallery. The screens below are specified in docs/issues/ and are built by the UX/UI team. This page is the entry point of the folder and is what the DevOps acceptance test checks.

Contract

  • One file per screen, named NN-screen-name.html.
  • Self-contained: every screen renders correctly from file://.
  • Shared CSS and JS live in assets/, referenced with relative paths.
  • Vanilla CSS and JS only — no framework, no bundler, no build step.
  • Colours come from tokens, never from literal values.
  • Empty, loading, validation-error, success and permission-denied states are part of each screen.

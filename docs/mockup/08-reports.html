Implementation note

Every row in both tables is a link to the transactions that make it up. The week labels start on Monday — "Week of 19 October 2026", running to 25 October — and the same WEEK_START constant drives the label and the query.

The category table reconciles: the row totals add up to the period total, and the shares add up to 100%. The "Uncategorised" row is present because entries without a category still belong in the report.

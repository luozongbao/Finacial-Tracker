Implementation note — for the developer

This screen is reached when ALLOW_REGISTRATION === false. The register route returns 403 and renders this page or an equivalent; the visitor-facing experience is the page above, not a status-code dump.

The gate is enforced on both sides: the page does not render a form, and the POST handler rejects the request independently. A check in only one of the two places is a bug.
